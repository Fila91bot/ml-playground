# 🧠 ML Playground

Browser-based Machine Learning demo using TensorFlow.js and MobileNet.

## Features
- Image classification using MobileNet v2
- Runs 100% in browser (WebGL)
- No backend needed

## Live Demo
https://ml-playground-one.vercel.app

## Tech Stack
- React
- TensorFlow.js
- Tailwind CSS
- Vercel

## Run locally
```bash
npm install
npm start
```
